AI 工作流 · Agent
· Vibe Coding

把 3 小時濃縮成一堂能實際操作的課。

整理：Mei｜課程來源：GARYTU AI 公開課｜本簡報為個人學習整理，非講師官方教材。

開場：這堂是把 Garytu 的 AI 工作流課精華重講一次，重點是「方法」不是「工具排名」。全程約 X 分鐘，中間有幾個現場 DEMO，看到青色 ◉ 就是我切到工具實操的地方。
// 全課的一句話

這堂課不教你「哪個 AI 最強」，
而是教你把每次成功與失敗的判斷，
留下來變成規則——
這才是唯一會複利的東西。

核心：強調「複利」。工具會過時、模型會換版，但你抽出來的判斷規則會一直累積。這句是整場的錨。
今天的路線
  1. 心態 從問題出發，不從工具出發
  2. 三個引擎 Skill · MCP · Agent 三層級
  3. 蒸餾 全課核心，會現場示範
  4. 畫家獨門 座標構圖 + 角色建置 prompt
  5. 影像方法論 分層 · 低成本漏斗 · 停損
  6. 接案定價 + 你的下一步
路線圖：讓聽眾知道有 demo、有 prompt 可抄。第 3、4 段互動最多。
// 01 心態

從「問題」出發，
不從「工具」出發

Q1
輸入是什麼？
資料 / 圖 / 文字 / 尺寸 / 影片
Q2
輸出要幹嘛？
發想 / 提案 / 內部測試 / 正式交付
Q3
誰驗收？
AI 自評 ≠ 客戶或你確認
Q4
失敗會怎樣？
重畫草圖，還是洩漏資料 / 燒點數
重點：AI 放大能力，也放大盲點。這四問答不出來，就別把任務全自動化。可請聽眾當場對自己一個案子回答。
// 02 三個複利引擎

Skill · MCP · Agent

SKILL
作業手冊
不是一次性 prompt，是把「何時用 / 輸入 / 流程 / 規則 / 驗收 / 例外」寫成可重複的文件。
MCP
連外部工具的介面
Skill 決定「怎麼做」，MCP 提供「去哪讀資料、建檔、執行」。原則：最小權限。
AGENT
三個自主層級
L1 固定流程 · L2 有邊界自主 · L3 高度自主。
L2 是商業預設
提醒：不是層級越高越好。Level 1 能穩定解決就別升級。L3 風險：費用累積、誤發、誤刪、資料外流。
// 03 蒸餾 — 全課核心

把「判斷」抽成
可重複的規則

原版本特徵 → 收到的意見 → 意見背後的真需求 → 採取的修改 → 是否改善 → 可重複規則
現場 DEMO：拿一個退稿案，當場抽一條規則
DEMO 1｜蒸餾（切到 Claude Code）
① 觸發：說「蒸餾這個案子」叫出 design-distill skill。
② 餵案例：「我要蒸餾一個被客戶大改的設計案：案件/用途＿；我原版本特徵＿；客戶意見原話＿；我當時怎麼改＿；改完結果＿。請用蒸餾公式抽 1~2 條規則，每條標『何時用/為何/何時不要』。」
③ 壓力測試：「這條規則放到＿（另一種案型）還成立嗎？不成立幫我補邊界。」
④ 存檔：「把這條存進 rules.md，用 R00 格式。」
⚠ 備援：先在家跑順、截圖存好；網路出包就秀截圖。先想好一個自家案例當備案，別全靠現場聽眾。
// 03 蒸餾

感受 → 規則

字再大一點
主標在手機縮圖一秒認不出時，優先加字級與字重、降背景細節；不要只加描邊（會破壞品牌氣質）。
畫面要高級
主視覺只能一個第一焦點，縮到手機仍能辨識；裝飾必須能說明與主題的語意關係。
不要太 AI
完稿前必過：縮小辨識 / 灰階 / 單色 / 實際尺寸 四道檢查。
關鍵：規則一定要標「何時不要」，否則會被無腦套用。陷阱：別一次把所有聊天塞進 Skill，先一成功案＋一失敗案對照。
// 04 畫家獨門 · 座標構圖

用座標「導演」畫面

focal ↑ 背對 guard left ×6 right ×11
X = 左右(−10~+10) · D = 深度(0前景→越大越遠) · Direction = 面朝方向
差異點：別人寫「一群人在街上」，他替每個角色標座標與朝向，連「哪裡留白」都寫進去。這是畫家的空間感，一般 AI 課教不到。
// 04 角色建置 · 3 步 prompt

一張圖 → 一整套角色

STEP 1　定位人物特色
讓這張參考圖人像站在攝影棚，背景顏色為＿，構圖為＿，動作為＿。A studio portrait…, background [色], composition [構圖], pose [動作].
STEP 2　各種拍攝角度　→　STEP 3　三視圖 turn-around
現場 DEMO：切到生圖工具，跑 STEP 1 → 3
DEMO 2｜角色建置（切到生圖工具，先上傳人像參考圖）
STEP1 定位特色：「讓這張參考圖人像站在攝影棚，背景顏色為＿，構圖為＿，動作為＿。」
STEP2 各種角度：「用同一個人物，生成正面／左右三分之二／左右側面／背面／半身／全身，保持臉型、髮型、五官、服裝完全一致。」
STEP3 三視圖：「建立三視圖（turn-around）。保持五官／髮色／眼型／服裝不變；不額外生成物件／飾品／Logo／材質；風格與原參考圖一致。」
⚠ 備援：參考圖先傳好；先在家跑成功、截圖備用，網路出包直接秀成果圖。
// 04 角色建置 · 一致性關鍵

三句「鎖定句」

  • 保持 X 不變facial features / hair color / eye shape / accessories / clothing
  • 不額外生成 Yno extra objects / details / accessories / textures / logos
  • 風格相似 Zsimilar to the reference image / an artist / an anime aesthetic

一致性不靠運氣，靠把「什麼不准變」講死。

金句：「一致性的關鍵不是生一張美圖，是三句鎖定句。」呼應下一段：主體用圖、特效用文字。
// 05 影像方法論

分層生成，別一次要全部

角色多角度鎖定→ 服裝→ 場景→ 動作→ 環境→ 特效最後才加
  • 主體用圖、特效用文字人物/產品/Logo 用乾淨參考圖鎖身份；霧、花瓣、光效用文字或後製加
  • 每完成一層，存一個可回復的基準版
為什麼：身份/服裝/場景/動作/光線/特效在同一次生成會互相競爭，改越多越走鐘。分層＋存基準版是解法。
// 05 低成本探索漏斗

別一開始就燒高畫質

L1文字確認 腳本/動作/鏡頭，刪掉不服務敘事的效果
L2靜態關鍵幀 用少量圖確認角色/場景/構圖
L3短秒數低成本測試 短秒數、關聲音、低解析
L4方向確認 存頭尾幀、記成功 prompt
L5正式生成 + 後製 才加秒數/解析/音效/補幀/放大

停損：命中率約三次一中。修比重做久，就換底圖 / 縮動作 / 拆兩鏡 / 換真人。

金句：「模型做不到時，先改製作設計，別用更長的提示詞掩蓋錯誤地基。」補幀救不了變形、放大救不了未成立的草稿。
// 06 接案定價

AI 變快，
專業不該變免費

客戶買的不是你花幾小時，是你的判斷與降低錯誤的能力。

  • 報價要算進商業範圍 · 複雜度 · 提案方向數 · 修改輪次 · 授權 · 出錯的商業風險
  • 合作倫理不繞過中間人——出錯一次就被封殺
  • 作品案例放判斷過程問題→怎麼拆→為何選→限制→如何驗收，不只放漂亮定稿
定位：設計師會越來越像跨域整合者，但跨域不等於什麼都接——知道何時找夥伴。
你的下一步
  • 今天：一張蒸餾對照表挑一個做完的案，抽 3~5 條規則（一成功＋一失敗）
  • 本週：一個小 Skill 草稿使用情境 / 輸入 / 流程 / 規則 / 驗收 / 資料不足要問什麼
  • 順手：試座標構圖 + 角色建置拿一張熟的畫面套格式，餵給生圖模型對照
收束：把行動壓到最小——今天只要一張對照表。別一次讀完所有東西。
